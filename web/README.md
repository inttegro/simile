# Simile browser console

The browser interface is embedded in the `simile` binary and served on loopback by the console.

Build the CLI and open a registered service:

```bash
cargo build -p simile-cli
./target/debug/simile console inttegro --web
```

The service name is optional. The console attaches to a matching running service or starts the
registered service itself, then opens the browser at a temporary loopback URL.

The source remains buildless: `index.html`, `styles.css`, and `app.js` are embedded with
`include_str!`. The browser consumes a sanitized service model generated by `simile-core` and polls
the running service's loopback-only inspection endpoints for exchanges, state, and deferred work.

Captured request data passes through the server's sensitive-field redactor. Opaque bodies are
omitted, large bodies are marked as truncated, and the exchange buffer is bounded in memory.
