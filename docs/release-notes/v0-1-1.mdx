Released November 17, 2026.

Simile 0.1.1 improves installation on macOS and Linux.

- The repository includes a stable shell bootstrap that selects a platform archive, verifies its
  checksum, and installs the binary.
- The release pipeline publishes Apple silicon artifacts from GitHub's supported macOS 15 runner.
